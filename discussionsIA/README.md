# Discussions IA

Un fichier distinct doit être créé ici pour chaque thème de travail.

## Convention de nommage

`AAAA-MM-JJ-nom-du-theme.md`

Exemple : `2026-07-28-page-accueil.md`

## Structure d’une discussion

```md
# Thème

## Contexte et objectif

## Avis de Codex

## Avis de Claude Code

## Décision retenue

## Implémentation et vérifications
```

Codex ne commence l’implémentation qu’après avoir relu l’avis de Claude Code, sauf instruction explicite contraire de l’utilisateur.
